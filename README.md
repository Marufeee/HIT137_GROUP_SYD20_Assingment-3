### Spot the Difference Desktop Application

This project develops a desktop-based “Spot the Difference” game using Python, Object-Oriented Programming, Tkinter GUI, and OpenCV image processing.

### Project Overview

The application loads an original image and automatically creates a modified version with 5 hidden differences. Both images are displayed side by side, and the player clicks on the modified image to find the differences.

### Main Features

- Uses proper Object-Oriented Programming with multiple classes.
- Loads common image formats such as JPG, PNG, and BMP.
- Uses OpenCV to generate image alterations.
- Displays original and modified images using Tkinter.
- Allows the player to click and detect hidden differences.
- Shows remaining differences and mistake count.
- Marks found differences with red circles.
- Includes a reveal button to show unfound differences with blue circles.
- Allows a maximum of 3 mistakes per image.
